# Fresha/Reservio Ink Landing Design

## Problem

Aktuální dev landing má příliš dekorativní pastelové pozadí. Oranžové a zelené ambientní fleky konkurují produktu, horní navigace působí drobně vůči hero H1 a sekce `#produktovy-pribeh` vypadá jako generický bento grid místo silného produktového důkazu.

## Direction

Směr je čistší Fresha/Reservio varianta: bílý top, větší navigace, tmavé ink ukotvení produktu a méně barevných dekorací. Barva má zůstat uvnitř samotného produktu jako stav rezervace, ne v pozadí stránky.

## Scope

- Zvětšit marketing header a navigační položky.
- Odstranit oranžové/mint ambientní fleky z hero a page backgroundu.
- Nahradit barevný proof gradient tmavým ink proof pásem.
- Převést `#produktovy-pribeh` z pastelového benta na čistší produktový panel.
- Ověřit landing guardem, screenshot metrikami a `npm run check`.

## Out Of Scope

- Nová informační architektura.
- Nové assety nebo externí screenshoty.
- Dashboard, booking flow, backend a tenant logika.
