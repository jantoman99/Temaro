# Temaro brand assets

Vsechny SVG soubory maji transparentni pozadi.

- `temaro-mark.svg` - samotny logomark pro favicon, ikony a male pouziti.
- `temaro-logo.svg` - horizontalni logo pro svetle pozadi.
- `temaro-logo-light.svg` - horizontalni logo pro tmave pozadi.

Primarni webove pouziti v aplikaci zustava komponenta `components/brand/temaro-logo.tsx`, aby slo barvy a velikosti bezpecne menit pres Tailwind.
